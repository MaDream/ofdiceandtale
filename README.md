# Of Dice and Tale

[ofdiceandtale.ru](https://ofdiceandtale.ru) — каталог материалов для настольных ролевых игр и Foundry VTT. Четыре раздела: ассеты, системы, модули, компендиумы. Интерфейс на русском и английском.

## Как добавить материал

В одной из четырёх общих папок Google Drive создайте папку проекта. Внутри разместите пару файлов с одинаковой основой имени:

```text
SibirPunk/
  SibirPunk.md
  SibirPunk.png
  SibirPunk.en.md    (необязательно)
  ...файлы проекта
```

- `.md` — русский текст в UTF-8. Первая строка `# Название` задаёт название карточки; остальные строки — описание. Поддерживаются абзацы, простые списки и заголовки, без исполнения HTML. Краткое описание удобнее читать в карточке.
- `.png` — баннер 320×160, максимум 8 МБ; желательно до 300 КБ.
- `.en.md` — необязательное английское название и описание. Без него английский интерфейс показывает русское описание с пометкой RU.
- Папка проекта, описания и баннер должны быть доступны «Всем, у кого есть ссылка», с возможностью скачивания.
- Пара может называться иначе, чем папка, если она единственная. При нескольких парах выбирается совпадающая с названием папки. Неоднозначность останавливает синхронизацию.
- Без полной пары `.md` + `.png` проект не публикуется. Проверяется один уровень папок проектов, архивы и их содержимое не обходятся.
- Карточка ведёт в папку проекта; заголовок раздела — в общую папку.

## Синхронизация и публикация

1. В Google Cloud включите Google Drive API и создайте API key. Application restrictions: None (запросы идут с GitHub Actions, не из браузера). API restrictions: только Google Drive API.
2. Добавьте ключ в Settings → Secrets and variables → Actions → `GOOGLE_DRIVE_API_KEY`. Не добавляйте его в файлы репозитория.
3. Settings → Pages → Source: GitHub Actions. Custom domain: `ofdiceandtale.ru`.
4. Actions → Sync Drive and publish Pages → Run workflow. `bootstrap` используйте только для первой публикации пустого сайта до настройки ключа; обычные запуски выполняйте без него.

Задача запускается ежечасно на 17-й минуте (UTC), при изменении кода и вручную. Расписание GitHub может задерживаться. Она скачивает только описания и баннеры, затем публикует готовые статические файлы. Ключ не попадает в сайт или журналы. При ошибке API, скачивания или разбора публикация не выполняется и прежний сайт остаётся доступным.

После успешной публикации задача коммитит время синхронизации в этот README (МСК), даже если каталог не изменился. Это также поддерживает активность репозитория. Если задача не работает более 60 дней, расписание может потребовать ручного включения.

Язык определяется по настройкам браузера: русский, если он входит в предпочитаемые языки; иначе английский. Ручной выбор сохраняется на устройстве. Внешние сервисы геолокации не используются.

## Локальная проверка

Node.js 24, без дополнительных пакетов:

```text
node --test
node scripts/sync.mjs --offline
node scripts/preview.mjs
```

Предпросмотр: http://127.0.0.1:4173. Для настоящей синхронизации задайте `GOOGLE_DRIVE_API_KEY` в окружении и выполните `node scripts/sync.mjs`. Папка `dist` — результат сборки, не исходники. При публикации автоматически запускаются проверки синхронизации.
